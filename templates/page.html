Keep Rolling

Starts each selected account's weekly usage window right after its reset, plus a random delay. Only providers whose weekly window starts on first use are pinged at the reset. Meta is pinged on a fixed interval instead, first at plugin start. At a reset, an active host cooldown for the account can be cleared once.

Management key

Enter the CLIProxyAPI management key. The page keeps it in memory only: reloading the page clears it.
